# 远程开发

## 定义
远程开发是指开发者通过网络（通常是 SSH）连接到位于远端（服务器、云端或集群）的开发环境，在该环境中进行代码编写、调试、运行和部署的工作模式。这种方式将本地 IDE 的交互体验与远端强大的计算资源（如 GPU、海量内存）和专用软件栈结合起来，使开发者不必在本地重现复杂的运行环境。

## 关键特征
- **资源分离**：开发界面（编辑器、终端）在本地，计算和运行环境在远端，典型通过 SSH 隧道实现。
- **强大的后端依赖**：适合需要 GPU 集群的深度学习、大规模数据处理，或依赖特殊硬件的场景。
- **环境复用**：远端环境一次配置，多开发者或多项目可共享，避免重复搭建。
- **命令行驱动**：大量操作通过终端完成，如切换盘符（Windows CMD）、启动服务、传输文件。
- **常用交互工具**：包括 [[entities/Jupyter-Notebook|Jupyter-Notebook]] 的远程浏览器访问、[[entities/nvidia-smi|nvidia-smi]] 监控 GPU、[[entities/scp|scp]] 安全传输文件、[[entities/pip|pip]] 导出 `requirements.txt` 等。
- **离线与协作**：远程会话可保持运行，断开重连后工作仍在；支持多人共用同一计算节点。

## 应用
- **深度学习与 AI 研发**：在配备 GPU 的服务器上训练模型，本地通过浏览器操作 [[entities/Jupyter-Notebook|Jupyter-Notebook]]。
- **大数据与科学计算**：运行需大内存或多核并行的任务，利用专用集群。
- **云端开发环境**：借助 VS Code Remote、JetBrains Gateway 等工具，将 IDE 连接到云主机。
- **教育与企业内训**：提供统一预配好的开发环境，学员或员工只需浏览器或轻客户端即可进入。
- **跨平台工作**：Windows 用户连接 Linux 服务器，利用 Linux 工具链；或反之通过 WSL 本地模拟远程流程。

## 相关概念
- [[concepts/环境管理|环境管理]]：管理远程服务器上的 Python/Conda 虚拟环境、系统级依赖，是远程开发的基础。
- [[concepts/文件传输|文件传输]]：通过 [[concepts/scp|scp]]、rsync 等工具在本地与远端间同步代码和数据。
- [[concepts/Linux系统管理|Linux系统管理]]：远程开发中需要掌握基本的 Linux 命令、服务启停（如手动启动 MySQL）和资源监控。
- [[concepts/版本控制|版本控制]]：远程协作时，通常通过 [[concepts/git|git]] 同步代码，并结合远端仓库。

## 相关实体
- [[entities/conda|conda]]、[[entities/mamba|mamba]] — 在远端管理 Python 环境和包依赖。
- [[entities/pip|pip]] — 从远端的 Python 环境中导出或安装包列表。
- [[entities/Jupyter-Notebook|Jupyter-Notebook]] — 远程安装并启动，通过本地浏览器访问交互式编程界面。
- [[entities/nvidia-smi|nvidia-smi]] — 远程监控 GPU 状态，合理分配算力。
- [[entities/scp|scp]] — 在本地与远程之间安全拷贝文件或文件夹。
- [[entities/MySQL|MySQL]] — 远程访问和启动数据库服务。
- [[entities/git|git]] — 在远端仓库与本地间同步代码，支撑远程协作。
- [[entities/Node-js|Node-js]]、[[entities/npm|npm]]、[[entities/nvm|nvm]] — 当远程开发涉及 Node.js 项目时用于环境管理。
- [[entities/MATLAB|MATLAB]] — 某些环境下需在远端运行 MATLAB 作业。
- [[entities/Vim|Vim]] — 作为无图形界面远程编辑器的利器。
