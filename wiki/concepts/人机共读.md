# 人机共读

## 定义
人机共读是 AI 知识底座设计的核心原则，指不要把「给人看的知识」和「给 Agent 看的知识」做成两套东西，而是让一套知识库同时服务人和 Agent 两个消费者。好的结构化知识应当人打开能读懂、能维护，Agent 检索和注入时精准高效。

## 关键特征
- 单一知识源：人读和 Agent 读共用一套知识库，不维护两套并行内容
- 双消费者兼容：人可读懂、可维护；Agent 可精准检索、高效注入
- 可维护性驱动：如果一条知识人看着都觉得莫名其妙，它的维护质量也不会好，时间一长就会腐败
- 长期保鲜基础：避免了知识系统因维护困难而失效，是结构化知识得以持续有效的根基

## 应用
- 作为 AI 知识底座结构设计的核心原则，决定每一条知识的格式、粒度与组织方式
- 指导团队知识沉淀流程：沉淀的经验既可供人审阅修订，也可供 Agent 直接注入使用
- 知识质量把关：以「人能不能读懂」作为判断结构化知识健康度的实用标准
