# 新人成长路径

## 定义

新人成长路径是作者在探讨 AI 时代组织管理时提出的方法论概念，指向一个核心管理难题：传统新人通过承担琐碎基础工作来逐步培养专业"感觉"，但当 AI Agent 能在几分钟内产出 80 分答案时，新人的短期产出虽然提升了，真正的能力成长却未必发生。作者据此主张，组织不能只给新人一个能产出 80 分答案的 Agent，而要重新设计一条能让新人长成高手的成长路径。

## 关键特征

- **判断力危机**：新人如果没有经历过基础工作，就无法理解 Agent 为什么这样做，当 AI 给出一个"很像正确答案的错误"时也没有任何怀疑能力
- **成长与产出的张力**：AI Agent 让新人短期产出提升，但遮蔽了"通过笨拙实践长出判断力"的必经过程
- **六步重塑路径**：让新人解释 Agent 为什么这么做、比较不同方案、真正去见客户、看见错误造成的后果、在有人托底时做判断、为最终交出的东西签上自己的名字
- **管理重心的转移**：给新人一个能产出 80 分答案的 Agent 很容易，给他一条长成高手的路才是真正的管理
- **警惕"只会用 AI"**：作者最担忧的不是新人不会用 AI，而是新人只会用 AI 却再也没有机会长出自己的判断

## 应用

新人成长路径主要应用于 AI 转型背景下的组织人才建设。在知识型团队中，管理者可以据此重新设计带教机制：不让新人直接依赖 Agent 出结果，而是要求新人复述并解释 Agent 的推理过程、对比多个方案的优劣、带着输出到真实场景中接受检验，并为最终交付物署名负责。该方法适用于正在推进 [[concepts/全员AI化|全员AI化]] 的组织，尤其是那些担心 AI 工具短期提效却削弱人才根基的团队。通过有人托底的安全环境中练习做判断，新人得以在 AI 时代保留"长出自己的判断"的机会。
