# 多模态输入

## 定义
多模态输入指 Claude Code 支持在对话中直接粘贴图片（如截图）的功能。用户无需将图片转写为文字描述，模型可直接处理视觉信息，从而在 UI 故障讨论、代码结构说明等场景中提升交互效率。

## 关键特征
- 直接在对话中粘贴图片，无需外部工具或上传步骤
- 模型原生支持视觉理解，无需人工转换为文字
- 降低沟通成本，尤其适用于传达界面问题、错误截图和流程图
- 将 Claude Code 的交互从纯文本聊天扩展至多模态对话
- 更精确地传递视觉上下文，减少描述歧义

## 应用
- 开发调试时粘贴 UI 错误或渲染异常的截图
- 提交问题报告时附带错误提示的截图
- 解释代码架构、依赖关系或算法流程图时使用图片
- 设计评审中直接展示界面原型或示意图
- 任何需要视觉参考来提高开发者与 AI 沟通效率的场景
