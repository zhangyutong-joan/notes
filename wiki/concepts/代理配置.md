# 代理配置

## 定义
代理配置是指为命令行工具（如 Git）设置网络代理，使工具能够通过本地代理服务器（例如科学上网工具的本地端口）访问外部网络资源。通过配置 `http.proxy` 与 `https.proxy` 参数，用户可以绕过直接网络连接的限制，在受限或隔离的网络环境中正常执行远程操作（如克隆仓库、推送代码）。

## 关键特征
- 针对命令行工具的代理设置，常用于 Git 等需要访问远程服务的程序
- 支持配置 HTTP 与 HTTPS 两类代理地址，例如：
  ```
  git config --global http.proxy "http://127.0.0.1:port"
  git config --global https.proxy "http://127.0.0.1:port"
  ```
- 代理地址通常指向本机运行的代理软件监听端口（`127.0.0.1:port`）
- 可暂时关闭 SSL 证书校验（`git config --global http.sslVerify false`）以应对自签名证书环境，但仅作为临时措施
- 配置级别支持全局（`--global`）或按仓库设置

## 应用
- 在企业内网或受限网络环境中，用于让 Git 顺利克隆、拉取和推送远程仓库
- 配合科学上网或 VPN 工具使用，使开发工具能够访问 GitHub、PyPI 等境外资源
- 在本地开发环境中解决因网络策略导致的 `git clone` 超时或连接失败问题
- 在其他命令行工具（如 `curl`、`pip`）中也适用类似的代理环境变量或配置文件方案
