# vim命令模式

## 定义
vim命令模式是 [[entities/Vim|Vim]] 编辑器中最核心的操作模式之一。用户通过按下 <kbd>ESC</kbd> 键从其他模式（如插入模式）切换到命令模式，然后在模式中以 `:` 开头输入 Ex 命令，从而执行保存、退出、搜索、替换、执行外部 shell 命令等一系列非文本输入的控制操作。该模式体现了 Vim 模式化编辑的哲学，是区分 Vim 与普通编辑器的关键特征。

## 关键特征
- **切换方式**：在任何模式下按 <kbd>ESC</kbd> 均可进入命令模式（部分命令如 `/`、`?` 可直接进入），状态栏会显示输入的字符。
- **命令前缀**：所有命令必须以冒号 `:` 开头，输入命令后需按 <kbd>Enter</kbd> 执行。
- **典型命令集**：
  - 文件操作：`:q`（退出）、`:q!`（不保存强制退出）、`:w`（保存）、`:wq`（保存并退出）。
  - 搜索与替换：`/pattern`（向下搜索）、`?pattern`（向上搜索）、`:s/old/new/g`（替换）。
  - 执行外部命令：`:!command` 可在 Vim 内临时调用 shell 命令。
  - 设置与帮助：`:set nu`（显示行号）、`:help`（查看帮助）。
- **模式记忆**：命令模式依赖于用户对命令的记忆，Vim 本身提供历史记录与补全（<kbd>Ctrl</kbd>+<kbd>D</kbd>）辅助操作。
- **强模式感**：相较于普通文本编辑器，Vim 通过命令模式将“编辑”与“控制”分离，使操作高度可组合，但也提高了学习曲线。

## 应用
- **日常编辑工作流**：在编写代码或配置文件时，熟练使用命令模式完成快速保存、退出、撤销、重做等操作，避免频繁离开键盘使用鼠标。
- **批量处理与自动化**：可通过命令模式执行复杂的全局替换、宏录制与回放，提高文本处理效率。
- **远程服务器维护**：在 SSH 连接的无图形界面环境中，Vim 是常用编辑器，命令模式是唯一进行文件控制的方式。
- **与其他工具集成**：许多 IDE 或编辑器插件提供 Vim 模式（如 VS Code 的 Vim 插件），命令模式的关键命令被模仿以提供一致体验。
