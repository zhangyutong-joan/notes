# 复盘 Agent

## 定义

复盘 Agent 是知识生产四模式中模式 B 的具体执行者，通常作为一个后台 Agent 周期性扫掠会话记录，识别知识供给中未命中的盲点，并自动生成 Git MR（Merge Request）补全知识。它把用户每次对话都变成一次知识质量检验：遇到回答不了的问题就触发知识补全，而不是依赖人写文档。复盘 Agent 连接了消费侧反馈与知识库更新，是知识飞轮保鲜环节的自动化引擎。

## 关键特征

- **后台周期性运行**：作为后台 Agent 定期扫掠会话记录，不打断用户工作流，以批处理方式完成知识补全
- **盲点识别**：从对话记录中识别知识库未能覆盖、未能回答的问题与知识缺口，而非依赖人工申报
- **自动生成 Git MR**：以 Merge Request 形式提交知识补全，使知识更新走代码化、可评审的治理流程
- **对话即质检**：将用户对话转为知识质量检验信号，回答不了的问题直接触发补全，绕开"等人写文档"的低效路径
- **高采纳率与周期保鲜**：以 O3 Buddy 复盘 Agent 为例，月均处理 1,097 条对话，采纳率达 92%，并实现每周自动更新
- **飞轮闭环枢纽**：处于知识飞轮保鲜环节，将消费侧反馈自动化反哺知识库更新

## 应用

- 作为模式 B 复盘补全的自动化执行引擎，周期性扫描对话与问答记录
- 自动发现并补全知识盲点，以 Git MR 形式提交，纳入代码评审与准入门禁流程
- 降低人工文档维护成本，用真实对话中的失败案例驱动知识库更新
- 在团队 AI 知识底座中承担保鲜环节，配合注入即记账、知识飞轮等机制形成自增强闭环
