# 远程开发技巧

## 定义
远程开发技巧是一系列在远程服务器（通常无图形界面）上高效进行开发、调试和运维的操作方法集合。其核心目标是解决远程环境下文件交互、服务访问、资源监控等高频痛点，通过简洁的命令行操作实现与本地开发类似的流畅体验。常见技巧包括 Windows 终端切换盘符、Jupyter Notebook 远程启动与访问链接获取、GPU 状态监控、`scp` 文件传输、MySQL 服务管理等。

## 关键特征
- 以命令行操作为主，适应无 GUI 的远程环境
- 覆盖开发全流程：环境准备、代码编写、数据交换、性能监控
- 强调实用性与可复用性，多为单条命令或简短脚本
- 特别面向云计算、远程集群、HPC 等场景
- 融合多种工具（Linux 命令、Git、Python 生态、数据库）的跨平台使用经验

## 应用
- 无图形界面下通过 `cmd` 或终端快速切换磁盘分区、浏览文件
- 远程启动 Jupyter Notebook 并获取包含 token 的访问 URL，实现本地浏览器调试
- 利用 `nvidia-smi` 或 `torch.cuda` API 实时监控 GPU 显存、温度与进程
- 使用 `scp` 在本地与远程之间高效传输文件/文件夹，例如 `scp -r root@IP:/path 本地路径`
- 管理远程 MySQL 服务的启动、状态查看与连接
- 配合版本控制（Git）完成代码同步与协作
