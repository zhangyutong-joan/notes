# 知识包

## 定义
知识包是知识分发的容器，用于按场景将相关知识打包，并主动注入给对应的 Agent。它把知识从长文档转化为结构化卡片、YAML、Prompt 模板等形式，使 Agent 能够高效消费，同时配合 [[concepts/注入即记账|注入即记账]] 实现可追溯。

## 关键特征
- **按场景打包**：围绕具体使用场景组织知识，而非笼统地提供整份长文档
- **主动注入**：采用定向推送而非撒网式推送，知识被精准送到需要的 Agent
- **订阅制分发**：每个 Agent 只订阅自己需要的知识包；如需求评审 Agent 只看需求模板和历史踩坑，舆情 Agent 只看判定标准和 bad case 规则
- **两类知识包**：安全中心团队已有 40 个知识包，分为仓库专属包和公共包两种
- **结构化呈现**：将知识转化为结构化卡片、YAML、Prompt 模板等易消费形式
- **可追溯**：配合 [[concepts/注入即记账|注入即记账]] 实现注入即记账

## 应用
- 安全中心团队的知识分发：通过 40 个知识包管理仓库专属知识与会共知识
- 需求评审 Agent：订阅需求模板与历史踩坑知识包，减少重复踩坑
- 舆情 Agent：订阅判定标准与 bad case 规则知识包，提升判定一致性
- [[entities/AI-端到端研发平台|AI 端到端研发平台]] 的知识供给：让不同 Agent 按需获取知识
