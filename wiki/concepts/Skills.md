# Skills

## 定义
Skills 是 **可复用的领域任务流程或标准操作程序（SOP）的封装**。它属于[[concepts/上下文工程|上下文工程]]中的流程标准化概念，将特定领域的操作步骤抽象为可重复调用的单元，供 AI Agent 在类似任务中高效复用，从而提升执行的一致性与效率。

## 关键特征
- **可复用性**：Skills 一旦定义，即可被 Agent 在相同类型的任务中重复调用，避免重复发明流程。
- **标准操作程序封装**：每个 Skill 封装了一个清晰、结构化的步骤序列，例如代码评审检查清单、发布检查表等。
- **领域特异性**：Skills 通常针对具体场景（如视频画面校准、UI 审查），其内容与领域知识紧密绑定。
- **Agent 友好**：Skills 以结构化提示或可执行流程的形式存在，Agent 能直接理解并按步骤执行。
- **可积累性**：通过持续实践和反馈，Skills 可以被优化和扩展，形成用户或团队的知识库资产。

## 应用
- **代码评审**：定义代码评审 SOP，包含代码风格、逻辑检查、安全漏洞排查等步骤。
- **UI 检查**：封装页面排版、交互响应、多端适配的检查清单。
- **发布流程**：标准化上线检查项，如版本号确认、灰度发布、监控告警等。
- **视频画面校准**：图像亮度、色彩、对比度的标准化校准流程。
- **上下文整理助手的输出**：[[concepts/上下文整理助手|上下文整理助手]] 最终会将高频、重复的任务流程识别为潜在的 Skills 建议，供用户封装为可复用的知识单元。

## 相关概念
- [[concepts/Memory|Memory]]：Memory 存储了用户的偏好和上下文，而 Skills 则封装了可执行的操作流程，二者共同构成上下文工程的知识库基础。
