# 知识生产四模式

## 定义

知识生产四模式是 AI 知识底座中并行运作的四种知识生产方式，包括模式 A 绑定流程自动沉淀、模式 B 复盘 Agent 驱动更新、模式 C Agent 自动生成、模式 D 运营处置即时沉淀。其铁律是「别指望人主动写」，依靠流程保证知识的持续产出，使知识成为流程的副产品而非额外工作。

## 关键特征

- 四种模式并行运作，覆盖研发和运营两大类场景
- 模式 A：绑定流程自动沉淀——知识随开发/运营流程自动入库
- 模式 B：复盘 Agent 驱动更新——由 Agent 复盘既有知识并推动更新
- 模式 C：Agent 自动生成——由 Agent 独立产生新知识，可将知识上线周期从天级压缩到 30 分钟
- 模式 D：运营处置即时沉淀——运营处置动作直接沉淀为知识，最短 2 小时完成入库
- 铁律是「别指望人主动写」，以流程机制而非个人意愿作为知识持续产出的保障
- 实践数据中 99.7% 的知识由流程自动沉淀，验证了「流程副产品」路线的有效性

## 应用

- 研发场景：将知识生产绑定到研发流程，在编写、评审、部署等环节自动沉淀知识
- 复盘场景：通过复盘 Agent 对既有知识进行审视和更新，保持知识底座的新鲜度
- 知识加速生成场景：利用 Agent 自动生成知识，显著缩短知识上线周期
- 运营处置场景：将运营中的处置动作即时转化为知识，快速完成入库
- 整体上服务于 [[concepts/AI-知识底座|AI 知识底座]]，让知识供给不依赖人的额外投入，支撑 [[concepts/知识飞轮|知识飞轮]] 的自增强运转
