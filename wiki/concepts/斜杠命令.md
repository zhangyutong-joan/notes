# 斜杠命令

## 定义
斜杠命令（Slash Commands）是 [[entities/Claude-Code|Claude-Code]] 交互式会话中以 `/` 开头的一组内置指令，用于快速执行会话管理、配置调整与操作类任务。用户无需记忆复杂的 CLI 语法，只需输入 `/` 开头的关键词即可控制 AI 的行为与当前会话的状态，是 Claude Code 的核心交互方式之一。

## 关键特征
- 以 `/` 符号开头，与普通对话消息和 CLI 命令（如 `claude` 启动参数）明确区分
- 属于内置命令集，无需额外安装或配置即可使用
- 覆盖会话生命周期管理：清除历史、压缩上下文、恢复对话、退出会话等
- 支持文件操作回滚与重做（`/undo`、`/redo`）
- 提供配置与用量查看功能（`/config`、`/cost`）
- 可通过 `/help` 查看全部可用命令，降低学习成本
- 与 CLI 启动命令共同构成 Claude Code 的完整命令体系

## 应用
- 在 Claude Code 交互式编程助手会话中，用户通过 `/init` 分析项目并生成 [[concepts/CLAUDE-md|CLAUDE.md]]
- 使用 `/clear` 清除当前对话历史，开启全新会话上下文
- 使用 `/compact` 主动压缩对话内容以释放上下文窗口，避免超出 Token 限制
- 使用 `/resume` 从历史记录中恢复之前保存的对话
- 使用 `/undo` 与 `/redo` 撤销或重做最近的文件修改操作
- 使用 `/config` 查看和调整 Claude Code 的配置项
- 使用 `/cost` 查看当前会话的 Token 使用情况
- 使用 `/login` 进行账号登录或切换
- 使用 `/exit` 优雅退出当前交互式会话
