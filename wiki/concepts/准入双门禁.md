# 准入双门禁

## 定义

准入双门禁是知识治理的第一道闸门：只有同时满足「已上线」与「已关联仓库」两个客观信号的知识，才能正式进入 Agent 引用池；未上线或未关联仓库的知识一律暂存，待满足条件后才能自动转正。该机制意在防止半成品、无效文档以未经验证的状态涌入知识库，保证 Agent 实际引用的都是经过客观信号验证的知识。

## 关键特征

- **双条件准入**：必须同时满足「已上线 + 已关联仓库」两个条件，缺一不可
- **客观信号验证**：以系统可识别的客观信号（上线状态、仓库关联）作为入池判定依据，而非主观判断
- **暂存而非丢弃**：未达标知识进入暂存区，后续上线或完成关联后可自动转正
- **防淹没**：阻止半成品、无效文档淹没知识库，保持引用池的内容质量
- **前置闸门**：作为知识治理体系的第一道关卡，先于后续质量分级与淘汰机制生效
- **通用可迁移**：其逻辑可迁移到提测通过、上线完成、事件关闭等业务流程中的必经节点

## 应用

- **Agent 引用池准入控制**：决定哪些知识可被 Agent 引用，过滤未经验证的低质量内容
- **知识库质量治理**：与三层质量分级、自动退场 + 复活兜底等机制协同，构成完整的知识治理链路
- **研发流程质量关卡**：将「必须经过客观信号验证」的思路迁移到提测通过、上线完成、事件关闭等业务必经节点，防止未达标事项进入下一阶段
- **自动转正机制**：知识在暂存区等待条件成熟，一旦满足双门禁要求即自动进入可引用状态，减少人工干预
