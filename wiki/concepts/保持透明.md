# 保持透明

## 定义
“保持透明”是构建有效 AI Agent 的第二项核心原则。它要求将 Agent 的规划步骤、执行日志与决策轨迹以可解释的方式呈现给用户与开发者，使 Agent 的行为不再是难以理解的“黑箱”，而成为可追溯、可审计、可修正的开放过程。这种透明设计不仅是调试与优化的基础，更是建立用户信任、提升系统可靠性和人机协作质量的前提。

## 关键特征
- **规划可观察**：Agent 在行动前将拟定的计划、工具调用顺序和推理路径显式展示
- **执行过程全记录**：每步操作的具体输入、输出和中间结果都生成完整的执行日志
- **决策依据可追溯**：明确展示决策所依据的证据、评估分数或上下文信息，消除“暗盒”猜测
- **可解释与可审计**：外部观察者可以独立复现行为，并能对错误路径进行人工干预和修正
- **信任构建基石**：透明性直接降低用户对 Agent 行为不确定性的焦虑，是长期信任的必要条件

## 应用
- 在 Agent 开发循环中，通过输出链式思考（Chain-of-Thought）或结构化日志，让开发者实时掌握系统状态
- 在生产环境里，透明日志用于审计追踪、合规检查以及故障根因分析
- 与用户交互时，将关键推理步骤以自然语言展示，增强用户对 Agent 建议的理解和采纳
- 结合其他原则（如 [[concepts/保持简单|保持简单]]），在简洁与可解释性之间找到平衡，构建高健壮性的 Agent 系统
