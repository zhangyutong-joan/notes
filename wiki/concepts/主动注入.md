# 主动注入

## 定义
主动注入是一种知识分发方法：平台在 Agent 启动任务之前，就按具体场景把相关知识打包并主动塞入其上下文，而不是等 Agent 自己搜索。它把知识从被动检索切换为精准供给，确保所需知识 100% 确定到达 Agent。

## 关键特征
- **提前打包、按场景供给**：在任务开始前根据 Agent 的角色和场景预先打包知识，而非启动后再检索。
- **确定性到达**：主动注入确保知识 100% 到达，规避 Agent 自主搜索时"不确定是否调用"的问题。
- **订阅制分发**：12 个以上 Agent 各自拥有知识订阅，不同 Agent 只看与自身场景相关的知识。
- **解决三大痛点**：Agent 自己搜索不确定是否调用、长文档难以消费、知识使用无记录。
- **精准而非泛化**：例如需求评审 Agent 只看需求模板与历史踩坑，舆情 Agent 只看判定标准与 bad case 规则。

## 应用
- 在 [[entities/AI-端到端研发平台|AI 端到端研发平台]] 中，为不同职能 Agent（需求评审、舆情监测等）在任务启动前注入定制化 [[concepts/知识包|知识包]]，减少无关上下文干扰。
- 与 [[concepts/注入即记账|注入即记账]] 配合，让每次主动注入都有记录，解决"使用无记录"问题。
- 作为 [[concepts/AI-知识底座|AI-知识底座]] 的知识分发出口，把底座中的知识按场景主动送入对应 Agent。
- 为 [[concepts/知识飞轮|知识飞轮]] 提供高质量消费入口：知识被实际注入并使用后，反馈回流到底座，推动知识持续优化。
