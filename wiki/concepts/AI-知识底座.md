# AI 知识底座

## 定义

AI 知识底座是面向 Agent 消费的团队级知识供给系统，而非传统静态知识仓库。它解决检索精度和注入效率两个关键问题，让知识「产得出、找得准、喂得进、淘汰得掉」。其设计原则是人机共读——一套知识库同时让人能理解和维护、让 Agent 能精准检索和高效注入。与传统知识库追求存得多不同，AI 知识底座追求匹配得准、注入得快、过时的能自动淘汰。

## 关键特征

- **面向 Agent 消费**：以 Agent 的检索与注入需求为第一设计目标，而非以人工浏览为主要场景
- **人机共读**：同一套知识库既能被人类理解和维护，也能被 Agent 精准检索和高效注入
- **四层内容结构**：L1 公共基础、L2 业务领域、L3 场景策略、L4 事件增量，层层递进
- **动态淘汰机制**：过时的知识能自动淘汰，保持知识库的时效性与信噪比
- **双指标导向**：以检索精度和注入效率为关键性能指标，区别于传统仓库的存储量导向
- **知识全生命周期管理**：覆盖生产、匹配、注入、淘汰四个环节的闭环

## 应用

- **团队知识供给**：为团队级 Agent 应用提供结构化、可检索的知识底座，支撑日常开发与运维场景
- **企业 Agent 落地**：在企业级 Agent 开发中，作为上下文工程的基础设施，解决知识注入的精度与效率问题
- **知识飞轮驱动**：与[[concepts/知识飞轮|知识飞轮]]配合，通过持续使用反馈优化知识内容，形成自我增强循环
- **领域知识沉淀**：通过[[concepts/四层知识盘点|四层知识盘点]]将团队经验系统化分层，避免知识散落在个人脑中
- **增量知识管理**：L4 事件增量层用于快速捕获和沉淀新发生的事件经验，支撑后续检索与复用
