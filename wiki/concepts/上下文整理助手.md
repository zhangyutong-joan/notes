# 上下文整理助手

## 定义
「上下文整理助手」是一个专门设计的AI代理角色，旨在通过结构化、互动式的对话引导，帮助用户系统地组织和分类项目信息。它遵循上下文工程的原则，将用户零散、模糊的需求描述转化为清晰、可执行的规则，并最终输出可直接用于项目文件（如 `CLAUDE.md`）、Skills 任务流程管理及本次任务参考的材料。

## 关键特征
- **互动式引导**：采用逐步提问的方式与用户协作，每次最多提出 3 个问题，避免一次性输出大量模板或信息，确保认知负荷可控。
- **规则化输出**：能够将用户的自然语言描述提炼为结构化、可检验的规则，拒绝模糊的通用描述，贯彻了 [[concepts/输入清洗|输入清洗]] 与 [[concepts/防呆|防呆]] 的设计思想。
- **上下文工程实践**：工作流程紧密围绕 [[concepts/上下文工程|上下文工程]] 理念，关注信息的系统分类、关联与版本管理，体现在对 [[concepts/私有Context|私有Context]]、[[concepts/缓存边界|缓存边界]] 等机制的利用上。
- **人机协作闭环**：作为 Prompt Engineering 与 Agent 设计的典型应用，助手本身是一个 [[concepts/结构化角色|结构化角色]]，通过交互形成“提问-澄清-输出-反馈”的协作闭环。
- **多维度交付物**：最终输出通常包含建议写入项目 Memory 文件（如 `CLAUDE.md`）的规则段落、可启动的 Skills 流程参考以及本次任务所需的背景材料。

## 应用
- **项目初始化与规则沉淀**：在新项目启动或引入新工具（如 [[entities/Claude-Code|Claude-Code]]）时，帮助团队成员将项目约定、编码规范与协作流程快速转化为标准的 `CLAUDE.md` 或类似的项目 Memory 文件。
- **需求澄清与任务定义**：当用户需求模糊、分散时，通过引导式对话将意图收敛为具体可执行的 Steps 或 Skills，减少后续执行中的歧义。
- **跨会话信息对齐**：在需要持久化 Context 的场景中，协助整理会话历史中的关键决策与配置，并维护 [[concepts/缓存一致性|缓存一致性]]，避免因上下文断裂导致的知识损耗。
- **教学与工作流演示**：作为展示上下文工程、[[concepts/渐进式披露|渐进式披露]] 和结构化 Prompt 设计价值的典型用例，用于新成员培训或工作流推广。
