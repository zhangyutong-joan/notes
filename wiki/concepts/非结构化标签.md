# 非结构化标签

## 定义

非结构化标签是一种将难以塞进标准字段的信息特点化为标签、统一存储的数据组织方法。作者所在公司把内容数据、商务数据、合作数据尽可能沉淀为数据资产，那些"很难塞进标准字段里的东西"会作为特点被打成非结构化标签，再统一放进飞书多维表格。该方法服务于数据涌现的信念，为 Agent 后续调用和数据分析提供基础，是数据治理中连接原始信息与可用资产的关键环节。

## 关键特征

- **特点化而非标准化**：专门处理那些无法用标准字段（如表格中的固定列）描述的信息，将其提炼为标签
- **统一存储**：非结构化标签统一存放在飞书多维表格中，实现数据的集中管理
- **应存尽存原则**：即使当下看不出价值，也坚持尽可能多地记录和打标，标签不可能一次打得完美
- **长期主义**：承认打标过程很累、记录当下看似无用，但仍认为这些数据是长期数据资产积累的一部分
- **服务数据涌现**：非结构化标签的积累服务于"数据涌现"的信念，即数据量达到一定程度后会产生超越个体记录的价值
- **为 Agent 提供调用基础**：标签化的数据为后续 AI Agent 的调用和数据分析提供可用的结构化基础

## 应用

- **博主打标**：经纪团队日常工作之一就是给合作过的博主打标，将博主的合作特点、风格等信息沉淀为非结构化标签
- **商务与合作数据沉淀**：将商务数据、合作数据中难以标准化的部分转化为标签，统一存入飞书多维表格
- **数据资产积累**：作为企业数据治理的一部分，将原始信息转化为可调用的数据资产，让"应存尽存"的理念落地
- **AI Agent 数据支撑**：为 Agent 后续调用和数据分析提供经过标签化的基础数据，使 AI 能够更有效地利用组织积累的信息
