# 一些常用命令 - Summary

## 来源
- 原始文件: [[一些常用命令]]
- 收录时间: 2026-08-04

## 核心内容
这份笔记汇总了开发者日常使用的高频命令，涵盖 Linux 系统管理、Python 环境与包管理、Git 版本控制、远程服务器操作及 Windows 服务管理等多个场景。内容按工具类别划分，每条命令均附有简洁的中文注释，方便快速复制和查阅。笔记中详细记录了 [[entities/Anaconda|Anaconda]] 的安装、[[entities/conda|conda]] 和 [[entities/mamba|mamba]] 的虚拟环境操作、[[entities/Git|Git]] 的日常提交流程与代理配置，以及通过 [[entities/scp|scp]] 传输文件、通过 [[entities/Jupyter|Jupyter]] 远程启动、使用 [[entities/NVIDIA-GPU|NVIDIA GPU]] 监控命令等实用技巧，同时涉及 [[entities/pip|pip]] 导出 [[concepts/requirements-txt|requirements.txt]] 和 [[concepts/虚拟环境|虚拟环境]] 的创建与清理，最后补充了 [[entities/npm|npm]] 前端启动、[[entities/MATLAB|MATLAB]] 简单绘图、Vim 编辑和 Windows 下 [[entities/MySQL|MySQL]] 手动服务管理的操作。

## 关键实体
- [[entities/conda|conda]] – 创建、克隆和管理虚拟环境
- [[entities/mamba|mamba]] – 高效的包安装与环境管理
- [[entities/Git|Git]] – 远程仓库、分支同步和代理配置
- [[entities/Jupyter|Jupyter]] – 远程服务器端交互式开发
- [[entities/pip|pip]] – 包信息查看与依赖导出
- [[entities/Python|Python]] – 贯穿全部环境与命令的语言基础
- [[entities/scp|scp]] – 安全的远程文件传输
- [[entities/NVIDIA-GPU|NVIDIA GPU]] – GPU 状态监控与 CUDA 可用性检查
- [[entities/npm|npm]] – Node.js 项目依赖安装与启动
- [[entities/MySQL|MySQL]] – Windows 下手动启动服务
- [[entities/MATLAB|MATLAB]] – 快速绘图命令
- [[entities/Anaconda|Anaconda]] – 数据科学发行版及其安装

## 关键概念
- [[concepts/requirements-txt|requirements.txt]] – Python 项目依赖复现标准
- [[concepts/虚拟环境|虚拟环境]] – 项目隔离与环境可复现的基础

## 要点
- 提供 Linux 用户创建、权限修改、磁盘空间查看及重启等运维命令
- 涵盖 conda 与 mamba 的完整环境管理生命周期，支持从创建到删除的全流程
- 展示 Git 日常协作流程，包括 Fork 同步上游、代理设置和证书问题处理
- 总结远程开发利器：Jupyter 远程启动、GPU 实时监控、scp 文件传输
- 记录 pip 的包信息查询和 requirements.txt 导出，实现环境可复现
- 补充 Node.js 开发启动、Vim 快速退出与 Windows 下 MySQL 手动管理
