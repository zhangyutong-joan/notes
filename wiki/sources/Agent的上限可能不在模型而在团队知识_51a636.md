# Agent的上限，可能不在模型，而在团队知识 - Summary

## 来源
- Original file: [[raw/Clippings/Agent的上限，可能不在模型，而在团队知识.md]]
- Ingested: 2026-08-19

## 核心内容
本文记录[[entities/安全中心团队|安全中心团队]]从定目标、搭体系到跑通[[concepts/知识飞轮|知识飞轮]]的完整实践过程。文章核心论点是：**Agent 的输出质量直接取决于供给的知识质量**，团队知识供给要从传统「人写人读」的仓库转向「流程自动生产、Agent 消费、人做决策纠偏」的[[concepts/AI-知识底座|AI-知识底座]]。

实践方法包括：用[[concepts/四问定目标|四问定目标]]界定范围、按[[concepts/四层知识盘点|四层知识盘点]]盘清家底、通过[[concepts/五节点绑流程|五节点绑流程]]绑定[[entities/AI-端到端研发平台|AI-端到端研发平台]]实现 99.7% 知识自动沉淀、以[[concepts/准入双门禁|准入双门禁]]与[[concepts/三层质量分级|三层质量分级]]治理质量、用[[concepts/主动注入|主动注入]]加[[concepts/知识包|知识包]]提升消费效率。实测数据显示需求交付从天级压到小时级，知识月增速从 86 条升至 716 条。文章最终强调知识飞轮自增强：**交付越多 → 知识越厚 → Agent 越强 → 交付越快**，建议从单场景闭环切入再横向扩展。

## 关键实体
- [[entities/安全中心团队|安全中心团队]] —— 实践主体，腾讯技术工程体系的安全研发与运营团队，69 人参与端到端研发（占部门 57.5%），80 余位知识贡献者
- [[entities/AI-端到端研发平台|AI-端到端研发平台]] —— 端到端需求交付平台，12 个研发 Agent 是第一消费者，知识沉淀绑定在研发流程关键节点上
- [[entities/O3-Buddy|O3-Buddy]] —— 安全中心综合问题问答机器人，内置[[concepts/复盘-Agent|复盘-Agent]]每周自动扫描会话补知识，月活 50 人，采纳率 92%

## 关键概念
- [[concepts/AI-知识底座|AI-知识底座]] —— 核心概念，面向 Agent 消费的团队级知识供给系统，追求匹配得准、注入得快、自动淘汰
- [[concepts/知识飞轮|知识飞轮]] —— 自增强闭环机制：交付越多、知识越厚、Agent 越强、交付越快
- [[concepts/人机共读|人机共读]] —— 一套知识库同时服务人与 Agent 两个消费者，避免两套系统割裂
- [[concepts/知识生产四模式|知识生产四模式]] —— 绑定流程自动沉淀、复盘 Agent 驱动、Agent 自动生成、运营处置即时沉淀，铁律是「别指望人主动写」
- [[concepts/知识治理|知识治理]] —— 含[[concepts/准入双门禁|准入双门禁]]、[[concepts/三层质量分级|三层质量分级]]、[[concepts/有效期保鲜|有效期保鲜]]、[[concepts/自动退场-+-复活兜底|自动退场-+-复活兜底]]四件事，保证有进有出
- [[concepts/主动注入|主动注入]] —— 平台按场景预打包知识塞给 Agent，替代 Agent 自主搜索，100% 确定到达
- [[concepts/注入即记账|注入即记账]] —— 每条知识的消费自动记录，可追溯、可观测
- [[concepts/用即积累|用即积累]] —— 知识在使用中自动积累，用户每次对话都在查缺补漏
- [[concepts/结构化知识|结构化知识]] —— 带适用条件、结论、应做/不应做的卡片，检索精准、注入高效
- [[concepts/MCP|MCP]] —— Model Context Protocol，Agent 调用外部工具的标准协议
- [[concepts/知识库三种形态|知识库三种形态]] —— 文档型、结构化存储、RAG 向量型，需组合使用
- [[concepts/敢于不沉淀|敢于不沉淀]] —— 反直觉设计：知识密度比体量重要，低价值内容自动跳过

## 要点
- **Agent 的上限在知识供给**：输出质量直接取决于能给它的知识质量，上 Agent 后知识供给是必须解决的工程问题
- **范式转变**：从「人写人读」的静态仓库转向「流程自动生产、Agent 消费、人做决策纠偏」的供给系统
- **别指望人主动写**：将知识沉淀绑定研发/运营必经节点，实测 99.7% 知识由流程自动沉淀
- **人机共读**：[[concepts/结构化知识|结构化知识]]让检索精准、注入高效，同时人看得懂才好维护、不易腐败
- **主动注入优于自主搜索**：平台按场景打包[[concepts/知识包|知识包]]注入 Agent，解决自搜不确定、长文难消费、使用无记录三大问题
- **治理防膨胀**：准入双门禁、三层质量分级、90 天[[concepts/有效期保鲜|有效期保鲜]]、自动退场复活，系统自己会代谢
- **飞轮自增强**：交付越多、知识越厚、Agent 越强、交付越快——从单场景闭环切入再横向扩展
