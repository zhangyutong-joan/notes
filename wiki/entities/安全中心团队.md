# 安全中心团队

## 描述

安全中心团队是[[sources/Agent的上限可能不在模型而在团队知识_51a636]]所述实践的主体团队，来自腾讯技术工程体系，负责安全研发与运营。该团队在 Agent 成为一线生产力后，系统搭建了[[concepts/ai-知识底座|AI 知识底座]]，并围绕[[concepts/知识飞轮|知识飞轮]]推动知识持续沉淀与复用。全部门共有 69 人参与[[entities/ai-端到端研发平台|AI 端到端研发平台]]的端到端研发，占部门人数 57.5%，知识贡献者超过 80 人。团队部署的[[entities/o3-buddy|O3 Buddy]]安全中心综合问题问答机器人月活约 50 人，复盘 Agent 每周自动扫描会话记录以补充知识。通过这套体系，安全中心团队把需求交付从天级压缩到小时级，代码审查从半小时到两小时降到平均 3.4 分钟，取消舆情巡检通宵班，并将风险事件日处置量从 400 条提升到 1200 条。
