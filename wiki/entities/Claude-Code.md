## 描述
Claude Code 是由 [[entities/Anthropic|Anthropic]] 公司推出的一款命令行 AI 编程助手，允许开发者在终端中直接与 Claude 模型交互，执行代码理解、生成和修改任务。该工具提供了一套完整的交互式会话（REPL）系统，用户可通过 `/init` 等 [[concepts/斜杠-init|/init]] 命令快速分析项目并生成 [[concepts/CLAUDE.md|CLAUDE.md]] 文件，为后续对话提供持久化的项目上下文。Claude Code 同时支持 [[concepts/CLI命令|CLI命令]]（如 `claude`、`claude -c`、`claude update`）和丰富的 [[concepts/斜杠命令|斜杠命令]]（如 `/clear`、`/compact`、`/cost`），帮助用户管理会话和成本。此外，它还支持 [[concepts/多模态输入|多模态输入]]（可直接粘贴图片）以及使用 `@` 符号指定文件等功能，大幅提升了开发效率。其命令体系设计清晰，围绕 Claude Code 这一核心产品展开，并有多家学习平台（如 [[entities/菜鸟教程|菜鸟教程]]）作为参考资料，便于用户上手。
