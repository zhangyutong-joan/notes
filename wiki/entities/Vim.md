# Vim

## 描述
Vim 是一款从 vi 发展而来的、高度可配置且功能强大的文本编辑器，广泛用于代码编写、配置文件编辑等任务。其最显著的特色是**模式化操作**，主要分为命令模式、插入模式和末行模式。源文件中指出，用户按 `ESC` 键可进入命令模式，随后通过 `:q` 实现不保存退出，或通过 `:wq` 保存退出。掌握命令模式是高效使用 Vim 的关键，相关概念详见 [[concepts/vim命令模式|vim命令模式]]。在 Linux 系统管理中，Vim 常作为默认或备选编辑器，是开发者与系统管理员必备的文本处理工具。
