# AutoPrompt Studio

## 描述
AutoPrompt Studio 是一个基于意图的提示校准工具，由 Eladlev 开发并托管于 GitHub。它采用 [[concepts/Intent-based-Prompt-Calibration|Intent-based Prompt Calibration]] 方法，通过分析用户输入的意图自动调整和优化提示，使大语言模型能够更准确地响应。该方法源自腾讯的研究，属于提示工程自动化领域的重要实践，旨在降低人工调优提示的成本。在源文件中被列为值得关注的好项目之一。
