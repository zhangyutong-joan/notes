# Node.js

## 描述
Node.js 是一个基于 Chrome V8 引擎的 JavaScript 运行时环境，使开发者能够在服务器端执行 JavaScript 代码。它采用事件驱动、非阻塞 I/O 模型，非常适合构建高性能网络应用、实时服务和命令行工具。源文件记录了在 Node.js 项目中利用 [[entities/nvm|nvm]] 管理版本，再通过 [[entities/npm|npm]] 安装依赖，最后以 `npm run dev` 启动开发服务器的典型流程。Node.js 拥有庞大的 npm 生态，广泛用于全栈 Web 开发、微服务架构和自动化脚本编写，是现代 JavaScript 全栈开发的基础平台。
