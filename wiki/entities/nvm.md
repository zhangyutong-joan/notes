# nvm

## 描述
nvm（Node Version Manager）是一个用于管理多个 [[entities/Node-js|Node-js]] 版本的工具，允许开发者在不同版本之间快速切换。它使得用户能够在同一台机器上同时安装多个 Node.js 发行版，并根据项目需求灵活选择合适的版本，从而避免版本冲突。nvm 通常与 [[entities/npm|npm]] 配合使用，为 Node.js 开发环境提供完整的版本控制能力。在源文件 [[sources/一些常用命令_c2949b]] 的 Node.js 启动部分中提到了 nvm，提示可能涉及通过 `rm` 命令清理旧版本的操作，进一步体现了它在环境维护中的作用。
