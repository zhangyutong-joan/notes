## 描述
npm（Node Package Manager）是 Node.js 的默认包管理器，提供命令行客户端和一个在线的包仓库（registry）。开发者通过 `npm install` 安装项目依赖，并通过 `npm run <script>` 执行 `package.json` 中定义的脚本，例如在源文件中使用的 `npm run dev` 启动开发服务器。npm 极大地简化了 JavaScript/Node.js 项目的依赖管理与分发，是 Node.js 生态系统的核心工具。日常工作中常与版本管理器 [[entities/nvm|nvm]] 配合使用，以切换不同版本的 Node.js 环境。别名：Node包管理器。
