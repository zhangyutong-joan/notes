# /resume

## 描述
`/resume` 是 [[entities/Claude-Code|Claude Code]] 中的一项 [[concepts/斜杠命令|斜杠命令]]，用于恢复之前中断的对话会话。当用户因意外退出、主动关闭或其他原因导致对话中断后，可以通过该命令从历史记录中选择并恢复特定的对话，从而直接衔接上一次的讨论上下文。这种能力让用户不必重新开始对话，显著增强了 Claude Code 的会话连续性与工作效率。
