# Obsidian Web Clipper

## 描述
Obsidian Web Clipper 是一个浏览器扩展，可将网页文章一键转换为 Markdown 格式并保存到 [[entities/Obsidian|Obsidian]] 的本地原始资料库中。它专门为快速收集网上内容而设计，适合用作 LLM Wiki 的素材来源，大幅降低手动整理的工作量。该工具配合 Obsidian 的设置与快捷键，还能自动下载文章内的图片到本地，保证图文引用的稳定性。在持续积累个人知识库的流程中，Obsidian Web Clipper 是高效的“输入”环节加速器。
